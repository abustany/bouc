# Bouc 🐏

Trivial booking platform for shared houses.

Allows people to mark when they'll use the house, shows all booking in a
calendar. Sends you an email when someone books days you've booked already.
Keeps a log of what changed over time.

## Major features NOT included

Anyone can access the page. Users identify using their name only. Use a reverse
proxy if you need stricter access control.
